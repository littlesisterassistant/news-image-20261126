## How it works

`main.py` (Python 3.13, standard library only) copies `entry.png` from this repository to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`), checking the file is a whole PNG or JPEG within the 1 MiB and 1024×1024 limits and verifying the copy by comparing bytes and reporting its sha256.

Run it:

```sh
python3 main.py
```
